A one-page newspaper front page summing up the world news of **Sunday, 22 November 2026**, drawn
programmatically and delivered as a single PNG.

## How it works

- `render.py` draws the front page (1024×1024 PNG) with Pillow from the day's reporting.
- `entry.png` is the rendered page committed beside the program.
- `main.ts` (Node 22, standard library only) copies `entry.png` to `/output/entry.png`
  (or to `$MAKEFUN_OUTPUT_DIR/entry.png` outside the grader's container).
